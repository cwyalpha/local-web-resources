# 许可受限资源

以下资源保留在服务器供已有项目使用，但新页面不得默认选择：

| 资源 | 注意事项 |
|---|---|
| Handsontable | 商业部署通常需要商业许可；非商业/评估密钥不能自动视为可用于内网生产。 |
| Intro.js | AGPL 或商业许可；闭源内网应用先确认组织政策。 |
| fullPage.js | GPLv3 或商业许可；内网/OEM 场景需单独核对。 |
| TinyMCE | GPLv2+ 或商业许可；自托管仍需按所选许可配置 license key。 |

规则：

1. 用户未明确许可条件时，优先选择 MIT/Apache/BSD/ISC 替代品。
2. 不删除已有文件，但在目录中保持 `license-gated` 状态。
3. 许可判断以组织法务政策和随资源附带的许可证为准，本文件只负责阻止模型误选。

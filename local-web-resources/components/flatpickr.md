# flatpickr

- 版本：4.6.13
- 分类：UI 组件
- 推荐级别：conditional
- 状态：available
- 说明：日期选择器
- 浏览器全局：`flatpickr`
- 许可：MIT
- 注意：中文语言包必须在 flatpickr.min.js 之后、初始化之前加载，否则会报告 invalid locale zh。

## 推荐入口

- CSS（head）：`{BASE_URL}/libs/ui-components/flatpickr/flatpickr.min.css`
- JS（body-end）：`{BASE_URL}/libs/ui-components/flatpickr/flatpickr.min.js`

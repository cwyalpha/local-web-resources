# plotly

- 版本：3.7.0
- 分类：数据可视化
- 推荐级别：specialized
- 状态：available
- 说明：科学、统计、3D 与金融图表
- 浏览器全局：`Plotly`
- 许可：MIT
- 注意：仅用于科学、统计、3D、金融图表或已有 Plotly JSON；普通业务图表优先 ECharts。尺寸变化后调用 Plotly.Plots.resize(gd)。Geo/LaTeX 不得回退公网：Geo 需本地 TopoJSON，LaTeX 需本地 MathJax。
